# «Радар»: UX и движение для очень занятого человека

Вторая версия макета на данных COO Hub. Данные, пороги и правила окраски те же, что в первой; поменялось всё, что касается ощущения от использования. Файл — `mockups/dist/m_hub_2026-09.html`, ролик на 35 секунд — `mockups/demo/coohub_radar_demo.mp4`.

## Три вопроса, три скорости

| Вопрос директора | Где ответ | Сколько времени |
|---|---|---|
| Как дела? | Радар: 13 точек по трём блокам, число в центре, одна фраза-вердикт | 3 секунды |
| Где болит и что с этим делать? | «Брифинг» — сторис на 35 секунд, или карточки «Где болит» | 30 секунд |
| Кому поручить? | «Где именно» → карта продуктов; «Поручение» → готовый текст в буфере | один жест |

Всё на одной странице. Переключатель разделов в шапке двигается вместе с прокруткой, поэтому навигация не требует запоминать вкладки.

## Принципы

1. **Движение объясняет, а не украшает.** Провалился в продукт — карта приближается изнутри нажатой плитки; вышел — отдаляется, и юнит сжимается обратно в свою плитку. Сменил юнит — числа досчитываются, а не перескакивают, поэтому видно, что изменилось. Apple HIG: «Add motion purposefully… Don't add motion for the sake of adding motion».
2. **Быстро.** Отклик на касание — 110 мс, смена состояния — 240–340 мс, зум — 480 мс. NN/g называет окно 100–500 мс; дольше анимация начинает мешать.
3. **Один яркий момент, остальное спокойно.** Сборка радара при первом открытии занимает меньше полутора секунд и не повторяется. Кинематографичный режим — только брифинг, и он запускается кнопкой, а не сам.
4. **Жест продолжается физикой.** Шторка тянется за пальцем и уходит с его скоростью: пружина с затуханием ≈ 0,93, без «резинового» отскока.
5. **Движение необязательно.** При включённом «Уменьшить движение» анимации выключаются целиком, досчёт чисел и зум заменяются мгновенным переходом. Статус никогда не передаётся только движением или только цветом: круг — красная зона, ромб — жёлтая, галочка — норма, кольцо с точкой — порог пробит внутри.
6. **Современный веб, с запасным путём.** Название метрики «перелетает» из строки в заголовок шторки через View Transitions API — с октября 2025 это Baseline во всех основных браузерах (Chrome 111+, Safari 18+, Firefox 144+). Где API нет, шторка просто выезжает на пружине.

## Система движения

| Токен | Значение | Где |
|---|---|---|
| Нажатие | 110 мс, масштаб 0,97 | все кнопки и плитки |
| Базовый переход | 240 мс, ease-out | цвета, индикатор разделов |
| Выразительное замедление | `cubic-bezier(.05,.7,.1,1)` (Material 3 emphasized decelerate) | зум карты, график, индикатор |
| Пружина шторки | жёсткость 420, затухание 38 | открыть, вернуть, закрыть с инерцией |
| Досчёт чисел | 520 мс, кубическое замедление | смена юнита, шторка при провале внутрь |
| Пульс красных точек | 2,6 с, только у красных | радар |
| Сборка при первом открытии | до 1,5 с | радар, вердикт, карточки |

## Жесты

| Жест | Что происходит |
|---|---|
| Касание точки радара | открывается карточка метрики; на компьютере наведение показывает имя и значение в центре кольца |
| «Брифинг» | сторис: касание справа — дальше, слева — назад, удержание — пауза, свайп вниз — закрыть; при сворачивании вкладки ставится на паузу |
| Свайп карточек «Где болит» | следующая проблема; точки-пейджер показывают, где вы |
| «Поручение» | текст задачи с цифрой, порогом, худшими юнитами и call_to_action — в буфер обмена; если буфер недоступен, текст открывается выделенным |
| «Где именно» | прокрутка к карте продуктов, худший юнит подсвечивается |
| Касание плитки | провал внутрь; радар, карточки и список пересчитываются по юниту |
| Стрелка или хлебные крошки | выход наружу обратным зумом |
| Ведение пальцем по графику | число в шапке показывает выбранный месяц, подсказка — 2026 и 2025, лёгкая вибрация там, где браузер её поддерживает |
| Тянуть шторку вниз | закрывается с инерцией пальца; касание юнита внутри шторки не закрывает её, а перетекает в дочерний юнит |

Ссылка с `#brief` на конце открывает сразу брифинг — удобно переслать директору.

## Чего сознательно нет

- Скелетонов и спиннеров: данные лежат внутри файла, ждать нечего.
- Параллакса, 3D и конфетти.
- Автозапуска брифинга при открытии.
- Текста, написанного «искусственным интеллектом». Вердикт собирается по правилам из порогов витрины, поэтому его можно воспроизвести и проверить.
- Кнопки «Поделиться»: в песочнице артефакта Web Share заблокирован, поэтому поручение копируется в буфер.

## Цвета статусов проверены, а не подобраны на глаз

Светлая тема: `#D1392E` / `#B98A00` / `#13824F` — проходят все проверки валидатора палитр: различимость при обычном зрении ΔE 18,2, при дальтонизме 8,7, контраст к фону ≥ 3:1. Тёмная тема: `#FF6A5C` / `#F2B13C` / `#3DD28A` — ΔE 17,2 и 8,2, контраст ≥ 3:1. Красный и зелёный при дальтонизме всё равно близки, поэтому форма значка обязательна везде.

## Что проверить на живом директоре

Не «понравилось ли», а поведение за первые две недели:
- открыл ли брифинг сам, без напоминания;
- нажал ли «Поручение» хотя бы раз;
- проваливался ли в продукты глубже первого уровня.

Если брифинг открывают, а в карту не ходят — карту можно убрать из первой версии. Если наоборот — брифинг можно не развивать.
